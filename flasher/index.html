Install Uptime Sentinel

Version {{VERSION}} · project page and guide

This page puts Uptime Sentinel onto your board over USB. Nothing to install on your computer. It needs Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). Phones, Firefox and Safari cannot talk to USB serial devices.

1. PLUG IN YOUR BOARD

Use a USB data cable. Some cheap cables only charge and will not work.

2. PICK YOUR BOARD

Board {{BOARDS}}

3. INSTALL

This browser cannot flash a board. Open this page in Chrome or Edge on a computer.

This page must be opened over HTTPS to use USB.
  1. Click Install and choose your board's port in the box that appears. It is usually called USB Serial, CH340, CH9102 or CP210x.
  2. Confirm, and wait about two minutes.
  3. When it finishes, the board restarts and shows a SETUP screen. Carry on with Step 5: Connect it to your WiFi.

IF SOMETHING GOES WRONG

  • No port in the list: try another cable, then install the USB driver for your board's chip: CH340 / CH9102 from wch-ic.com (search "CH343 driver"), or CP210x from silabs.com.
  • It cannot connect: hold the board's BOOT button while you click Install, and let go once it starts writing.
  • Blank screen afterwards: the wrong board was picked. Pick another and install again.

ALREADY RUNNING UPTIME SENTINEL?

Installing from this page resets the board's settings (WiFi, webhook, admin password). To move to a new version and keep everything, use Update firmware on the monitor's own dashboard instead, with the -update.bin file for your board from the releases page.
